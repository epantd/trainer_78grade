1. IP-адрес

Состоит из 4 чисел (октетов), разделенных точками. Каждое число от 0 до 255.
Пример: 192.168.1.10

2. Маска сети

Показывает, где в IP-адресе находится адрес сети, а где номер компьютера.
В двоичном виде маска всегда состоит сначала из единиц, а потом из нулей.
1 = адрес сети, 0 = адрес компьютера.

МаскаДвоичный видНулей (для ПК)
255.255.255.0...11111111.000000008
255.255.255.192...110000006
255.255.255.224...111000005
255.255.240.0...11110000.0000000012

3. Как найти адрес сети?

Нужно применить операцию побитовое И (умножение) к IP-адресу и маске. Там, где в маске стоят нули, в адресе сети тоже будут нули.

Пример: IP 192.168.1.15 и маска 255.255.255.0.
Последний байт IP = 15, маски = 0. 15 И 0 = 0. Адрес сети: 192.168.1.0.

4. Как найти номер компьютера (адрес узла)?

Номер компьютера — это та часть IP-адреса, которая соответствует нулям в маске.
Пример: IP 206.158.124.67, маска 255.255.224.0.
Последний байт маски 224 = 11100000. Значит, номер компьютера — это последние 5 бит IP.
67 = 01000011. Берём последние 5 бит: 00011 = 3.

5. Сколько компьютеров в сети?

Считаем количество нулей в маске (назовем его n).
Общее количество адресов = 2n.
Количество компьютеров = 2n − 2 (вычитаем адрес сети и широковещательный адрес).
