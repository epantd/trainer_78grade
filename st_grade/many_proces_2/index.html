Синтаксис ВПР

ВПР(что_ищем; где_ищем; номер_столбца; 0)

1. Что ищем — значение из таблицы, по которому ищем совпадение в первом столбце диапазона.
2. Где ищем — диапазон таблицы (можно зафиксировать через $, чтобы не «съехал» при протяжке).
3. Номер столбца — порядковый номер нужного столбца внутри диапазона, начиная с 1.
4. 0 — точное совпадение.

Правила времени

Конец процесса — момент, когда процесс завершится. Он складывается из его длительности и наибольшего из времён окончания его зависимостей (если зависимостей нет — только из длительности).

Начало процесса — момент, когда процесс занимает процессор. Он получается из времени окончания с учётом длительности; помните, что моменты времени в задаче нумеруются с 1.

Проверка: длительность = конец − начало + 1. Если это равенство не сходится — где-то ошибка в расчётах.
