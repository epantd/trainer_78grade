Синтаксис ВПР

ВПР(что_ищем; где_ищем; номер_столбца; 0)
1. Что ищем — ID зависимости (ячейка C2 или D2).
2. Где ищем — диапазон $A:$H (вся таблица, знаки $ фиксируют).
3. Номер столбца — 8, потому что H — восьмой столбец от A.
4. 0 — ищем точное совпадение.

Правила времени

Конец (H): Длительность + МАКС(окончания зависимостей).
Начало (G): Конец − Длительность + 1.
Длительность: Конец − Начало + 1 (проверка).

Сортировка и фильтр

Сортировка: клик по заголовку упорядочивает данные по возрастанию/убыванию.
Фильтр: оставляет только строки, удовлетворяющие условию.
